# Reproducibility Status

This repository is being upgraded from a smoke-tested workflow scaffold toward a manuscript-level reproducibility package for Environmental Modelling & Software.

## Fully reproducible in the current checked state

- Raw dataset presence under `Data/raw/`.
- Primary and external Excel readability.
- Dataset audit outputs for row counts, column names, missingness summaries, required-column checks, and group-size diagnostics.
- Smoke-test execution for all stage scripts on tiny synthetic datasets.
- Leakage-control implementation for fold-wise imputation/scaling and group-out validation.

## Manuscript analyses with executable scripts, pending full remote execution

The following scripts are present and executable, but current checked outputs are smoke/audit outputs rather than final manuscript results:

- `scripts/01_primary_empirical_baselines.py`: Freundlich, KOC, and MLR baseline evaluation.
- `scripts/02_primary_ml_validation.py`: random split vs strict LOSO validation and generalization-gap calculation.
- `scripts/03_primary_layer_ablation.py`: Layer 1/2/3 descriptor ablation.
- `scripts/04_primary_ad_diagnosis.py`: support-distance, quartile, Q75 weak-support, and error-correlation diagnostics.
- `scripts/05_primary_few_shot_calibration.py`: few-shot target-soil additive calibration.
- `scripts/06_primary_error_decomposition.py`: soil-level and within-soil residual decomposition.

These analyses should be run on a machine with adequate compute resources before claiming complete manuscript reproduction.

## Smoke-tested only in the current checked outputs

- Model validation outputs under `outputs/primary` and `outputs/external` are not final manuscript results unless regenerated by full runs.
- `scripts/07_external_validation.py --smoke` runs a synthetic external-validation check.
- `scripts/07_external_validation.py` without `--smoke` currently performs a framework check on the real external dataset and intentionally does not execute full external validation.

## External-validation inputs still required

Full external validation requires confirmation of compound-level descriptors not present in the current external raw file:

- `logP`
- `logS`

Provide these via `compound_lookup_path` in `configs/external_neutral_organic.yaml`. The lookup table should include a reliable compound join key, preferably `CAS Number`, plus `logP` and `logS`. The workflow does not auto-fill, download, or infer these values.

The current inferred-soil entity rule is exact grouping by:

- `soil pH`
- `soil organic carbon`
- `CEC`
- `Clay`

This rule should be confirmed before final manuscript-level external validation.

## Manuscript value verification

Use `scripts/check_manuscript_values.py` after full outputs are generated. The script compares CSV/JSON output values with expected manuscript targets using tolerances. Its built-in checks cover audit/smoke sanity values; manuscript metric targets can be supplied through a YAML config when final table/figure values are fixed.
